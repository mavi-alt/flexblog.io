# FlexBlog

Blog hipotético desenvolvido no curso de [CSS Flexbox](https://www.origamid.com/curso/css-flexbox/) da Origamid.

O projeto tem como objetivo praticar o uso de Flexbox para criar uma landing page responsiva e visualmente moderna, com foco em layout de blog e destaque de conteúdo.

## Funcionalidades
1. Layout responsivo
2. CSS puro
3. Landing page estilizada
4. Estrutura modular e fácil de manter
5. Design moderno voltado para blog

## Tech Stack
- HTML
- CSS
